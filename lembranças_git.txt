VOLTAR VERSÃO
git log --oneline            <- lista todos os ultimos commits
    (head -> main) é o ultimo commit
    (origin/main) é o ultimo push
        se a msm versao tiver head -> main e tb o origin/main quer dizer q a versão do cumputador esta igual ao github


git revert hash/head     --> cria um novo commit desfazendo as alterações do commit/hash escolhido		(pode dar conflito se tiver feito alteração na msm linha)
git revert --abort          --> cancela o q ficou pela metade na hora do revert


git reset --hard hash      --> isso volta pra como era naquela versão do hash, perdendo tudo oq foi feito depois inclusive o historico


git restore --source=hash  ---> o código volta para como estava no hash escolhido, sem alterar o histórico de commits
